# 머신러닝 기초 2·3일차 — 복습 노트 핵심 요약

원본: `머신러닝 기초 2·3일차 복습 노트.pdf` (36쪽, 2026-11-06). 본 문서는 원본의 수업 6~13 핵심을 간추린 요약본입니다.

## 1. 분류와 평가 지표 (수업 6~8)
- **분류**는 범주(이탈/잔류)를 예측한다. **양성(Positive)**은 좋은 결과가 아니라 찾아야 하는 대상이다.
- 혼동행렬: **TP** 올바른 양성, **TN** 올바른 음성, **FP** 음성을 양성으로 오탐, **FN** 양성을 놓침.
- **정밀도** = TP/(TP+FP): 찾아낸 것 중 진짜의 비율.
- **재현율** = TP/(TP+FN): 실제 대상 중 찾아낸 비율.
- **F1**은 정밀도·재현율의 조화평균, **AUC**는 여러 임계값에서의 분류 구분 능력을 요약하는 지표다.
- 클래스 불균형에서는 정확도만 보면 오해하기 쉽다. **임계값·class_weight·리샘플링**으로 놓침과 오탐의 균형을 조절한다.
- 사례: 고객 이탈 예측에서 임계값 0.5 → 0.3으로 재현율 **56.3% → 76.6%**, 정밀도 **66.8% → 53.0%**. 최적 선택은 업무상 오류 비용과 대응 가능 인원에 따라 달라진다.

## 2. 모델 비교와 군집 (수업 7·9)
- 로지스틱 회귀, 의사결정 트리, 랜덤포레스트, kNN을 **교차검증**으로 비교한다. 훈련 성능과 검증 성능의 큰 차이는 과적합을 의심하게 한다.
- 심장질환 데이터의 교차검증 정확도: 로지스틱 **84.8%**, 트리 **75.2%**, kNN **62.0%** (수업 실습 결과).
- **k-means**는 정답 레이블 없이 비슷한 데이터를 군집으로 묶는다. 거리 기반이므로 표준화가 중요하고 **k(군집 수)** 및 군집 이름·대응 전략은 사람이 결정한다.
- 고객 7,043명을 4군집으로 구분했으며, C군집 2,276명의 이탈률은 **48.2%**였다.

## 3. 딥러닝과 사전 학습 모델 (수업 10~12)
- 신경망은 층마다 특성을 추출하고 **가중치를 갱신**하며 학습한다. 지나친 복잡도는 과적합을 초래할 수 있다.
- **사전 학습 모델**은 이미 학습된 가중치를 이용한다. **파인튜닝**은 목적에 맞는 데이터로 추가 학습하는 방식이다.
- 이미지 분류에서는 입력 크기·정규화 등 **모델별 전처리**가 필요하다.
- MobileNetV2 실습: 상품 사진 **13장 중 6장** 정답. 오류 원인은 배경, 촬영 각도, 사전 학습된 클래스 범위와의 차이. Top-k 확률은 실제 정확도와 다르다.

## 4. 텍스트 분류와 LLM (수업 13)
- 텍스트 처리: **토큰화 → 토큰 ID → 임베딩 → 모델 입력**.
- 부정 리뷰 분류에서 목표가 미탐지 최소화라면 **재현율**을 우선한다. 수업의 모델 변경으로 재현율 **81.6% → 92.3%**, 놓친 부정 리뷰 **184건 → 77건**.
- 분류 모델은 대량의 정해진 범주 처리, LLM은 요약·답변 작성처럼 복합 작업에 적합하다.
