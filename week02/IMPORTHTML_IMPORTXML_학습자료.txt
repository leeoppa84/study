2주차 추가 학습 자료: Google 스프레드시트로 웹 데이터 가져오기
작성일: 2026-10-28

학습 목표
- IMPORTHTML로 웹페이지의 표를 가져온다.
- IMPORTXML로 RSS에서 필요한 정보를 골라 가져온다.
- 가져온 데이터로 비교표와 소식 모음표를 만든다.

이 함수들은 Google 스프레드시트의 셀에 입력하는 수식이다.
앞서 배운 Python의 rabbit.move()와는 실행 환경이 다르다.
수식은 =로 시작하고, 주소와 텍스트는 일반 큰따옴표(")로 감싼다.


1. IMPORTHTML: 웹페이지의 표 또는 목록 가져오기

1-1. 어떤 일을 하나요?
웹페이지의 HTML에 들어 있는 표나 목록을 시트로 가져온다.
표 내용을 일일이 복사하지 않고, 주소와 표 번호를 지정해 불러올 수 있다.

기본 문법:
=IMPORTHTML("웹페이지 주소", "table", 표번호)

각 인수의 뜻:
- 첫 번째: 데이터를 가져올 웹페이지의 전체 주소(https:// 포함).
- 두 번째: 표는 "table", 목록은 "list".
- 세 번째: HTML 소스에서 몇 번째 표 또는 목록인지 나타내는 번호.
  Google 공식 문서의 번호는 1부터 시작한다.
  표 번호와 목록 번호는 각각 따로 센다.

1-2. 기상청 예제로 따라 하기
① 새 Google 스프레드시트를 열고 시트 이름을 '날씨원본'으로 바꾼다.
② A1 셀에 다음 수식을 입력한다.

=IMPORTHTML("https://www.weather.go.kr/w/obs-climate/land/city-obs.do", "table", 1)

③ 외부 데이터 액세스 허용 안내가 뜨면 내용을 확인하고 허용한다.
④ 가져온 표가 펼쳐질 수 있도록 A1 오른쪽과 아래쪽 셀을 비워 둔다.
⑤ 결과의 관측 시각, 지점명, 열 제목을 기상청 원문과 비교한다.

수업에서 입력한 원래 수식:
=IMPORTHTML("https://www.weather.go.kr/w/obs-climate/land/city-obs.do", "table", 0)

학습 자료에서는 공식 문법에 맞춰 0을 1로 정리했다.
기존 시트에서 0으로 결과가 나오더라도 표 번호를 설명할 때는
공식 기준인 1부터 시작한다. 페이지 개편으로 원하는 표의 순서가
달라졌다면 2, 3 등 다른 번호를 확인해야 한다.

2026-10-28 웹페이지 확인 시 위 주소는 아래 주소로 이동했다.
https://www.weather.go.kr/w/weather/land/city-obs.do

기존 주소로 불러오지 못하면 이동 후 주소로도 확인한다.
=IMPORTHTML("https://www.weather.go.kr/w/weather/land/city-obs.do", "table", 1)

웹페이지가 열린다는 사실만으로 Sheets의 가져오기 성공이 보장되지는 않는다.
사이트의 접근 정책이나 HTML 변경에 따라 결과가 달라질 수 있다.

1-3. 주소와 표 번호를 셀에 나누어 관리하기
새 시트 '날씨설정'에서 다음과 같이 입력한다.

A1: 웹페이지 주소
B1: https://www.weather.go.kr/w/weather/land/city-obs.do
A2: 표 번호
B2: 1

A4 셀에 입력:
=IMPORTHTML(B1, "table", B2)

B1은 주소가 들어 있는 셀을 참조하므로 따옴표를 붙이지 않는다.
주소나 표 번호를 바꿀 때 수식 전체를 다시 작성할 필요가 없다.
이 예제는 앞의 A1 직접 입력 예제와 별도 시트에서 실행한다.

1-4. 어떻게 활용하나요?
- 도시별 날씨 비교: 원본 표를 불러온 뒤 지점명과 기온을 확인한다.
  필터로 관심 도시를 고르거나, 숫자로 인식되는 기온 열을 정렬한다.
- 지역 조사: 공개된 HTML 통계표나 시설 목록을 가져와 비교한다.
- 시점별 변화 기록: 같은 표의 결과를 날짜별 시트에 '값만 붙여넣기'로
  저장한다. IMPORTHTML 자체는 과거 기록을 계속 쌓아 주지 않는다.

활용 순서:
가져오기 → 열 제목·시각 확인 → 필요한 행 선택 → 비교·정렬 → 해석

기온에 단위나 기호가 섞여 있으면 문자로 들어올 수 있으므로
숫자 정렬·계산 전에 셀의 실제 값을 확인한다.


2. IMPORTXML: 구조에서 필요한 정보 골라 가져오기

2-1. 어떤 일을 하나요?
XML이나 HTML의 구조를 따라가며 원하는 부분을 가져온다.
RSS는 새 글의 제목, 링크, 발행일 등을 구조화해 제공하는 형식이다.
홈페이지 주소와 RSS 피드 주소는 서로 다를 수 있다.

이번 학습의 기본 문법:
=IMPORTXML("RSS 주소", "XPath")

- 첫 번째: RSS 원문이 제공되는 주소.
- 두 번째: XML 구조에서 가져올 부분을 지정하는 경로인 XPath.
- 선택 인수 locale도 있지만, 이번 실습에서는 두 인수만 사용한다.

수업에서 배운 수식:
=IMPORTXML("RSS 주소", "/rss/channel/item")

여기서 "RSS 주소"는 설명용 자리표시자다.
실제로 실행하려면 RSS 피드 URL로 바꿔야 한다.

2-2. /rss/channel/item은 무슨 뜻인가요?
다음은 이해를 돕기 위해 만든 RSS 2.0 구조 예시다.

<rss>
  <channel>
    <title>학습 소식</title>
    <item>
      <title>2주차 자료 공개</title>
      <link>https://example.com/week02</link>
      <pubDate>Wed, 28 Oct 2026 09:00:00 +0900</pubDate>
      <description>이번 주 학습 안내입니다.</description>
    </item>
  </channel>
</rss>

- /rss: 문서 맨 위의 rss 요소로 간다.
- /channel: 그 안의 channel 요소로 간다.
- /item: 그 안에 반복되는 게시물 항목들을 선택한다.
- /title: 제목 요소를 선택한다.
- /link: 원문 링크 요소를 선택한다.

따라서 /rss/channel/item/title은 '각 게시물의 제목'을 뜻한다.
/rss/channel/title은 '피드 자체의 제목'이다. 서로 다르다.

item 전체를 선택하면 여러 하위 요소의 내용이 함께 반환될 수 있다.
표를 깔끔하게 만들려면 title, link 등 필요한 하위 요소를 지정한다.

2-3. 실제 RSS로 제목 가져오기
공개 예제: BBC World News RSS(영문)
https://feeds.bbci.co.uk/news/world/rss.xml

2026-10-28 원문 확인 시 rss/channel/item 구조와
title, link, pubDate 요소가 존재했다. 항목 수와 내용은 바뀐다.

새 시트 'RSS제목'의 A1에 '제목'을 쓰고 A2에 입력한다.
=IMPORTXML("https://feeds.bbci.co.uk/news/world/rss.xml", "/rss/channel/item/title")

A2 아래로 제목이 펼쳐질 공간을 비워 둔다.
본인이 관심 있는 기관·언론사·블로그의 RSS 2.0 주소로 바꿔도 된다.
단, 피드마다 구조가 다르므로 같은 XPath가 항상 통하는 것은 아니다.

2-4. 제목·링크·발행일을 나란히 가져오기
새 시트 'RSS소식'에서 다음과 같이 입력한다.

A1: RSS 주소
B1: https://feeds.bbci.co.uk/news/world/rss.xml

A3: 제목
B3: 원문 링크
C3: 발행일

A4:
=IMPORTXML($B$1, "/rss/channel/item/title")

B4:
=IMPORTXML($B$1, "/rss/channel/item/link")

C4:
=IMPORTXML($B$1, "/rss/channel/item/pubDate")

$B$1은 수식을 복사해도 참조 위치가 바뀌지 않도록 고정한 셀 주소다.
각 열의 결과가 아래로 펼쳐질 수 있도록 빈칸을 확보한다.
발행일은 문자로 들어올 수 있어 날짜 계산 전에 형식·시간대를 확인한다.

주의: 이 예제처럼 각 item에 제목·링크·발행일이 하나씩 있을 때
세 열을 나란히 비교하기 쉽다. 일부 항목에서 요소가 빠져 있거나
가져오기 시점 사이에 새 글이 추가되면 열 사이 행 대응이 어긋날 수 있다.
제목과 링크 몇 쌍을 원문과 대조한 후 활용한다.

2-5. 필요한 항목만 가져오기
B1에 RSS 주소가 들어 있는 'RSS소식' 시트 기준이다.

첫 번째 게시물의 제목:
=IMPORTXML($B$1, "/rss/channel/item[1]/title")

피드에 나열된 순서에서 앞의 5개 게시물 제목:
=IMPORTXML($B$1, "/rss/channel/item[position()<=5]/title")

[1]은 첫 번째 item을, position()<=5는 앞의 다섯 item을 고른다.
첫 항목이 최신 글인지는 피드의 정렬 방식과 발행일로 확인한다.

RSS가 아닌 Atom 피드는 feed/entry 등 다른 구조를 사용한다.
네임스페이스가 있는 XML도 경로 처리가 달라질 수 있다.
아무 결과도 나오지 않으면 RSS 원문의 태그부터 확인한다.

2-6. 어떻게 활용하나요?
- 관심 분야 소식 모음: 제목·링크·발행일을 모아 읽을 글을 고른다.
- 기관 공지 확인: RSS를 제공하는 기관의 공지 목록을 시트로 모은다.
- 콘텐츠 아이디어 정리: 제목을 읽고 분류, 메모, 아이디어를 정리한다.
- AI 요약 준비: 필요한 항목을 값으로 복사해 저장한 뒤 AI에 전달하고,
  원문 링크로 요약의 정확성을 확인한다.

제목과 짧은 설명만으로는 기사 전체 내용을 알 수 없다.
직접 쓴 메모를 계속 갱신되는 IMPORTXML 결과 옆에만 두면,
목록 순서가 바뀔 때 다른 글과 연결될 수 있다.
기록용 시트에는 결과를 값으로 저장하고 원문 링크와 메모를 함께 남긴다.


3. 두 함수의 차이와 선택 기준

IMPORTHTML
- 선택 기준: HTML의 몇 번째 표·목록인가?
- 필요한 정보: 페이지 주소, "table" 또는 "list", 번호
- 예: 기상청 관측 표, 공개 통계표

IMPORTXML
- 선택 기준: XML·HTML 구조의 어떤 요소인가?
- 필요한 정보: 원문 주소, XPath
- 예: RSS 게시물 제목, 원문 링크, 발행일

웹페이지의 표 전체가 필요하면 IMPORTHTML부터,
RSS의 특정 항목이 필요하면 IMPORTXML부터 생각한다.
두 함수 모두 URL과 선택 기준을 바꿔 활용 범위를 넓힐 수 있다.


4. 오류가 날 때 확인할 순서

① 수식 입력
- 맨 앞의 =, 일반 큰따옴표, 쉼표, 괄호가 맞는지 확인한다.
- 시트 지역 설정에 따라 인수 구분자가 세미콜론(;)일 수 있다.

② 결과가 펼쳐질 공간
- #REF!와 '배열 결과를 펼칠 수 없다'는 안내가 나오면
  오른쪽·아래쪽의 값과 병합 셀을 확인한다.
- 지우기 전에 기존 데이터가 필요한지 확인하거나 빈 시트로 옮긴다.

③ 외부 접근 허용
- 액세스 허용 안내가 있는지 확인한다.
- 조직 계정에서 관리자가 차단한 주소라면 관리자 설정이 필요하다.

④ URL과 데이터 구조
- IMPORTHTML: 해당 주소에 HTML 표·목록이 있는지, 번호가 맞는지 확인한다.
- IMPORTXML: 일반 홈페이지가 아닌 RSS 원문 주소인지, XPath가 맞는지 확인한다.
- #N/A만 보고 '데이터가 없다'고 단정하지 말고 자세한 오류 메시지를 읽는다.
- 로그인, 접근 차단, 자바스크립트로 나중에 생성되는 내용은
  브라우저에 보여도 이 함수로 가져오지 못할 수 있다.

⑤ 요청량과 결과 크기
- 가져오기 수식을 과도하게 복제하지 않는다.
- 결과가 너무 크면 item[position()<=5]처럼 XPath 범위를 줄인다.

⑥ 갱신과 기록
- Google 안내에 따르면 문서가 열린 동안 매시간 업데이트를 확인한다.
  실시간 갱신이나 닫힌 문서의 정기 수집을 보장하는 기능은 아니다.
- 브라우저 새로고침만으로 함수 갱신이 강제되지는 않는다.
- 과거 값을 남기려면 별도 시트에 날짜·출처와 함께 값만 붙여넣는다.


5. 짧은 실습과 확인 질문

실습 A: 날씨 표 가져오기
1) 기상청 표를 가져온다.
2) 관측 시각과 지점명 열을 확인한다.
3) 관심 있는 도시 두 곳의 기온을 원문과 대조한다.
4) 결과를 기록용 시트에 값으로 저장하고 관측 시각·출처를 적는다.

실습 B: RSS 제목 가져오기
1) RSS 주소를 B1에 넣는다.
2) /rss/channel/item/title로 제목을 가져온다.
3) /rss/channel/item[position()<=5]/title로 바꾼다.
4) 링크 수식을 함께 확인하고 제목 두 개가 올바른 원문으로 연결되는지 확인한다.

확인 질문
- IMPORTHTML의 표 번호 1은 무엇을 뜻하나요?
- RSS 주소와 일반 홈페이지 주소는 어떻게 다른가요?
- /rss/channel/title과 /rss/channel/item/title은 무엇이 다른가요?
- 가져온 결과가 바뀌어도 나의 메모를 정확히 유지하려면 어떻게 해야 하나요?

답안 요점
- HTML 소스의 첫 번째 표를 뜻한다.
- RSS 주소는 게시물 정보가 담긴 XML 피드를 제공한다.
- 전자는 피드 제목, 후자는 개별 게시물 제목을 선택한다.
- 결과를 값으로 저장하고, 원문 링크와 메모를 함께 기록한다.
